❓ HOW TO PLAY

1. One person taps CREATE ROOM and shares the 4-letter code.

3. Everyone taps READY. The host taps START GAME.

4. You play 5 random mini-games out of 8.

5. Points are added up. The winner is crowned ABSOLUTE CHAOS CHAMPION.

Controls: Desktop = WASD / arrow keys / mouse. Mobile = touch joystick & big buttons.
